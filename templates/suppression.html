SR-001 services C · Persistence modified · added · removed T1543.003
Suppresses When
Modified: MS-signed service (signing_status=Valid), only state/start_type changed, plus Windows Update confirmed (Event ID 19) or key in known high-churn set (WaaSMedicSvc, gpsvc, BITS, TrustedInstaller…)

Added/Removed: per-user instance pattern (BaseName_XXXXXX, 5–8 hex chars) from known bases (OneSyncSvc, WpnUserService, CDPUserSvc…), signing_status=Valid
Never Suppresses
binary_path, run_as, display_name changes; unsigned binary (signing_status≠Valid); unknown base names; change_type=modified on per-user instances
SR-002 critical_binary_hashes F · Filesystem modified T1027 · T1036
Suppresses When
Windows Update confirmed (Event ID 19) and both baseline and current status=ok (binary exists and was readable in both snapshots)
Never Suppresses
No WU confirmation; status≠ok in either snapshot (binary disappeared or access denied); signed-but-different binaries without WU — a signed replacement could still be a downgrade to a vulnerable version
SR-003 installed_software_64 D · Software modified T1562
Suppresses When
Publisher unchanged and non-empty; version is an increment (not a downgrade); major version component unchanged (e.g. 2.x → 2.y is ok, 2.x → 3.0 is not)
Never Suppresses
Removals (T1562 — defensive tool removal); additions (new unbaselined software); publisher changed or empty; version downgrade; major version bump
SR-004 firewall_rules E · Network modified T1562.004
Suppresses When
Enabled toggled False → True; Action=Allow; both Action and Direction unchanged between snapshots (re-enabling a known-good Allow rule)
Never Suppresses
Additions (new rules always alert — may open attack surface); removals; Action changes (Block→Allow is critical); Enabled toggled in any other direction
SR-005 defender_status H · Audit modified T1562.001
Suppresses When
change.key is signature_version or signature_last_updated — these change on every definition update cycle and are expected high-frequency benign churn
Never Suppresses
Protection-state fields: antivirus_enabled, real_time_protection_enabled, am_service_enabled, nis_enabled — any change to these always alerts
SR-006 defender_exclusions H · Audit modified T1562.001
Suppresses When
Current list is a strict subset of baseline list — exclusions only removed, none added. Fewer exclusions = increased scan surface = safer.
Never Suppresses
Any addition to the exclusion list (T1562.001 — a common attacker move to allow malware to run undetected); mixed change (some removed, some added) treated as an addition
SR-007 dll_hijack_paths F · Filesystem added · modified T1574.001
Suppresses When
writable_by_users=False and exists=True in current snapshot — directory still exists and is locked down, not a hijack surface
Never Suppresses
Removals (PATH manipulation suspicious); writable_by_users=True (primary alert condition); exists=False (missing directory = future hijack surface — attacker can create and control it)
SR-008 scheduled_tasks C · Persistence added · removed T1053.005
Suppresses When
change.key starts with \SoftLanding\ — GUID-rotating Windows feature tasks that churn between cycles on this VM without meaningful drift
Never Suppresses
change_type=modified on SoftLanding tasks (unexpected and always alerts); any task outside the \SoftLanding\ path
SR-009 listening_ports E · Network modified T1049
Suppresses When
Port 135 (RPC Endpoint Mapper) owned by svchost.exe with only pid changed — svchost PID rotation between boots is normal OS behaviour and not a network change
Never Suppresses
Any field other than pid changed on port 135; any other port; process name other than svchost.exe
SR-010 firewall_rules E · Network added · removed T1562.004
Suppresses When
Rule name is a raw GUID and display_name matches a known Microsoft app (e.g. Teams) — these apps register and deregister GUID-named firewall rules at runtime on each launch or update cycle
Never Suppresses
GUID-named rules from unknown or non-Microsoft publishers; modified changes to GUID rules; non-GUID rule additions or removals
